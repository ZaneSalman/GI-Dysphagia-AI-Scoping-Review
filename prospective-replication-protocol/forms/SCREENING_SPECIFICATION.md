# Screening Specification

Title-and-abstract decisions are `Include`, `Exclude`, or `Unclear`. Full-text decisions are `Include`, `Exclude`, `Not retrieved`, or `Awaiting clarification`.

Each decision records Record ID, Report ID when assigned, reviewer, decision, criteria version, evidence-supported note when needed, and timestamp. Independent decisions are locked before consensus. Consensus records preserve both independent decisions, the resolved outcome, the reviewers, evidence considered, and timestamp.

Each excluded full-text report receives exactly one primary reason from `FULL_TEXT_EXCLUSION_CODES.csv`. Not-retrieved reports are not exclusions.
