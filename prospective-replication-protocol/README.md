# Prospective Protocol for a New Scoping Review Replication

This repository contains the prospective protocol for a new, from-scratch replication and re-analysis of *Artificial Intelligence Applications in Esophageal Dysphagia and Related Esophageal Disorders*.

Protocol version 1.0.1 is methodologically complete and ready for public deposit. It is not yet operative. The protocol becomes operative only after this exact version is committed, tagged, and released in a public GitHub repository before any replication-specific searching, exporting, deduplication, screening, retrieval, eligibility assessment, charting, or synthesis begins.

This protocol was derived from the methods and lessons of the completed review, but it governs a new review conducted from the beginning. The replication will independently search, deduplicate, screen, retrieve, chart, verify, and synthesize the evidence. Prior inclusion and exclusion decisions will not be imported as binding decisions.

## Activation

1. Upload this package to a public GitHub repository.
2. Commit the unchanged protocol as version 1.0.1.
3. Create tag `protocol-v1.0.1` and a public GitHub release.
4. Record the commit SHA, tag, release URL, public timestamp, and any archive DOI in `protocol/ACTIVATION_RECORD.md`.
5. Begin review work only after the public timestamp exists.

The prior completed review remains retrospective. This protocol applies only to the new replication and does not alter the chronology or registration status of the prior review. Protocol version 1.0.1 follows the JBI scoping-review protocol structure, including a PCC framework, three-step search, reviewer calibration, a charting instrument, and prespecified analysis and presentation.
