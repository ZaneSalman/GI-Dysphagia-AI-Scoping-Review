# Prospective Release Checklist

- [ ] Confirm no replication-specific review activity has begun.
- [ ] Confirm protocol version 1.0.1 and all source strategies are unchanged from the approved package.
- [ ] Confirm `JBI_CONFORMANCE_AUDIT.md` remains accurate after the final editorial review.
- [ ] Confirm the repository contains no copyrighted reports, database exports, credentials, private correspondence, or personal information.
- [ ] Commit the complete package to the public repository.
- [ ] Create tag `protocol-v1.0.1`.
- [ ] Create a public GitHub release from that tag.
- [ ] Archive the release with Zenodo or another permanent repository if available.
- [ ] Record the commit SHA, URL, timestamp, identifier, and checksum in `protocol/ACTIVATION_RECORD.md`.
- [ ] Verify that the public timestamp precedes the first review activity.
- [ ] Preserve later methodological changes in the amendment or deviation log.
